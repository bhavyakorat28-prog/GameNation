\# GameNation 🎮



GameNation is an online gaming store website developed as a college project.



\## About the Project



This project demonstrates a basic gaming store website using HTML.



\## Technologies Used



\- HTML5



\## Pages Included



\- Home

\- About

\- Categories

\- Products

\- Contact



\## Project Structure



\- `index.html` — Main entry page

\- `home.html` — Home page

\- `about.html` — About page

\- `categories.html` — Game categories

\- `products.html` — Products page

\- `contact.html` — Contact page
